<h2>UT00 - Introducción a Kotlin</h2>

<h3>Null → Ejercicios:</h3>

<h4>1. Crea una función getOrZero que reciba como parámetro un número entero opcional. Si el parámetro es null devuelve 0 y si no devuelve el valor del parámetro.</h4>

<h4>2. Crea una función printName que reciba un parámetro opcional llamado nombre. Si el nombre es null imprime "Nombre desconocido", si no imprime el nombre.</h4>

<h4>3. Crea una función getLength que reciba un parámetro opcional llamado nombre. Si el nombre es null devuelve null, si no es null devuelve la longitud del nombre.</h4>

<h4>4. Crea una función first que reciba como parámetro una lista de enteros. Si la lista está vacía devuelve null, si no está vacía devuelve el primer elemento de la lista.</h4>

<h4>5. Un método average(numbers: List&lt;Double&gt;) que calcula la media de los números en la lista. Si la lista está vacía devuelve null.</h4>

<h4>6. Un método max(numbers: List&lt;Double&gt;) que busca el máximo de los números en la lista. Si la lista está vacía devuelve null.</h4>

<h4>7. Un método min(numbers: List&lt;Double&gt;) que busca el mínimo de los números en la lista. Si la lista está vacía devuelve null.</h4>
